# Prediction Engine Project

Complete prediction system dengan Flutter mobile app dan Python backend.

## 📱 Flutter Mobile App

```cmd
cd flutter_app
quick_start.bat
```

**Features:**
- Real-time sensor monitoring
- AI prediction dengan confidence score
- Auto-refresh setiap 5 detik
- Manual input & live data

## 🔧 Full System

Untuk development sistem lengkap, lihat dokumentasi di:
- [`flutter_app/`](flutter_app/) - Mobile app
- [`src/`](src/) - Core ML engine
- [`simulasi_data/`](simulasi_data/) - Data simulation

## 🚀 Quick Development

1. **Mobile only:** `cd flutter_app && quick_start.bat`
2. **Full system:** `python main.py`
